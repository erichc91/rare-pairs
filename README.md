# Rare Pairs

Live page: https://erichc91.github.io/rare-pairs/

Each card is two things from fields that almost never talk to each other, like a heat wave in tissue during tumor ablation and a tilt wobbling in a gas disk around a star. Both follow the same equation. Each one is proven in Lean, a computer proof checker, to be the same law after rescaling.

The animation runs both worlds on the same random draws, so they can't disagree. They trace one shared curve.

## How the pairs were picked

I've been building an engine that reads equations out of about 150,000 papers and textbooks, sorts them into a small set of basic laws, and proves the matches in Lean. From that I scored every proven pair on three things:

- the two papers are from different disciplines
- the two papers don't cite each other and share no references
- both sides describe something real and nameable, not a toy example

Then I searched Wikipedia and the web for each of the top 30 to see whether anyone had already put them side by side. The 14 here came back with nothing.

## What "unseen" means

It means I couldn't find anyone naming these two things together. It doesn't mean nobody has ever noticed. The equations themselves are usually famous. What's rare is the pairing.

If you know of a paper that connects one of these pairs, I'd like to hear about it.
